Ghi chú:
- Bộ chuẩn dữ liệu đang theo common_v1 (tham chiếu từ common.txt).
- Quy ước epoch input: dataset_v001, dataset_v002, ...
- Fixed components (tag/conflict/common config) giữ ở root layer, không chia theo epoch.
- Runtime artifacts (ví dụ session state) tách riêng với input dataset.
- Layer1 đã migrate loader sang dữ liệu epoch.
- Layer2/Layer3 vẫn giữ một số file legacy ở root layer để tương thích code hiện tại.
